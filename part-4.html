07 · COLD START

No history is a feature state

Do not impute an invented prior event. Keep the first observed user, card and merchant events explicit.

1cold_startprior count = 0 · recency = NULL · velocity = 0
0repeat historyprior context exists; left censoring still applies

The source begins in 1991. “First observed” does not prove first-ever real-world activity.

08 · STRUCTURAL DEPENDENCY

Missing state is not automatically a new state

State familiarity is extended-only. When current state is missing, the feature remains `NULL`; channel/state dependency is audited before promotion.

EXTENDED ONLY

Comparable geography required

Online transactions can have systematically different state coverage. Treat missingness as availability evidence and monitor the dependency.

Missing current state → familiarity `NULL`, not `is_new = 1`.
