# Model–policy boundary

The frozen model estimates risk; the Part 7 policy chooses an action under economics, friction, and finite review capacity. A model champion/challenger is separate from a policy champion/challenger.

The policy does not retrain Part 5 or Part 6, use `fraud_label` as an input, or treat graph novelty as proof of fraud. It uses score bands for block/review eligibility and a deterministic queue for review allocation. Overflow is explicitly `ALLOW` unless a frozen configuration says otherwise.
