# Part 7 reason-code dictionary

Reason codes describe policy triggers, not causal explanations. The canonical registry is `config/part7/reason_codes.yaml`; row-level logs must remain in the external Drive-managed execution workspace and are never copied into or published from this repository.

Examples include score-band entry, high exposure priority, new card–merchant pair, cold card, new merchant, cross-community relationship, capacity priority, capacity overflow, and graph review overlay. A code must exist in the registry before it can appear in a decision log.
